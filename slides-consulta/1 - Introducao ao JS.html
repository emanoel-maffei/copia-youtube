O JavaScript no desenvolvimento web

De páginas estáticas a sites que reagem
Parte 1 · Slide 1

Revisando o tripé

Você já sabe construir a estrutura (HTML) e a aparência (CSS) de um site.

Hoje entra a terceira peça: o comportamento.

HTML

O quê existe na página

CSS

Como isso aparece

JavaScript

O que acontece quando o usuário interage

Parte 1 · Slide 2

O que o JS faz que HTML e CSS não fazem

HTML e CSS são declarativos: descrevem um estado fixo da página.

O JavaScript permite que a página mude sozinha, reaja a cliques, valide dados e converse com o usuário — tudo sem recarregar a página.
  • Reagir a cliques, teclas e movimentos do mouse
  • Mostrar e esconder conteúdo dinamicamente
  • Validar formulários antes de enviar
  • Buscar e exibir dados em tempo real
Parte 1 · Slide 3

Onde o JavaScript “mora”

Opção 1: inline, direto no HTML.

<script>
  console.log("Olá, mundo!");
</script>

Opção 2 (recomendada): arquivo externo.

<script src="script.js"></script>

Separar o JS num arquivo .js deixa o código mais organizado e reutilizável.

Parte 1 · Slide 4

Onde colocar a tag <script>

No <head>:

<head>
  <script src="script.js"></script>
</head>

O HTML ainda não existe quando o script roda — risco de erro.

Antes do </body>:

<body>
  ...
  <script src="script.js"></script>
</body>

O HTML já foi montado. É a forma mais segura e usada.

Parte 1 · Slide 5 · Console

O console do navegador

Todo navegador tem um console dentro das DevTools (F12).

console.log("Isso aparece no console!");
console.log("Idade:", 16);
  • É o principal jeito de depurar (debugar) código
  • Mostra erros, avisos e valores de variáveis
  • Não aparece para o usuário final, só para quem programa
02

Variáveis

Guardando informação para usar depois
Parte 2 · Slide 6

O que é uma variável

Uma variável é uma caixinha com nome onde guardamos um valor.

let nome = "Marina";
let idade = 16;
Sem variáveis, o programa não consegue lembrar de nada — nem o nome do usuário, nem o que ele digitou.
Parte 2 · Slide 7

let, const e var

let

Valor pode mudar depois. Uso mais comum no dia a dia.

const

Valor não muda depois de criado. Prefira sempre que possível.

var

Forma antiga. Evitamos usar — tem comportamentos confusos.

Regra prática: comece sempre pensando em const; só use let se o valor realmente precisar mudar.

Parte 2 · Slide 8

let vs const na prática

Com let, o valor pode ser reatribuído:

let pontos = 0;
pontos = 10;
pontos = pontos + 5;
console.log(pontos); // 15

Com const, reatribuir dá erro:

const site = "Meu Portfólio";
site = "Outro nome"; // ❌ Erro!
Parte 2 · Slide 9

Nomeando variáveis bem

Nomes claros tornam o código fácil de entender — inclusive para você, no futuro.

  • bom nomeUsuario
  • bom totalCarrinho
  • bom estaLogado
  • evite x, dado2
  • evite coisa
  • evite nomes em outro idioma misturado

Convenção usada em JS: camelCase — primeira palavra minúscula, as seguintes com inicial maiúscula.

03

Tipos de dados

Nem toda informação é igual
Parte 3 · Slide 10

Tipos primitivos

string

"texto entre aspas"

number

42 ou 3.14, sem aspas

boolean

true ou false

undefined

variável criada, mas sem valor

null

valor “vazio” de propósito

Parte 3 · Slide 11

Arrays: listas de valores

Um array guarda vários valores numa única variável, em ordem.

const cores = ["azul", "verde", "roxo"];
console.log(cores[0]); // "azul"
console.log(cores.length); // 3

O primeiro item sempre tem índice 0, não 1.

Parte 3 · Slide 12

Objects: dados organizados

Um object guarda valores associados a chaves (nomes).

const aluno = {
  nome: "Pedro",
  idade: 17,
  ativo: true
};
console.log(aluno.nome); // "Pedro"

Objects são ótimos para representar “coisas do mundo real”: um usuário, um produto, um post.

Parte 3 · Slide 13

Descobrindo o tipo com typeof

O operador typeof revela o tipo de um valor:

typeof "olá";     // "string"
typeof 10;        // "number"
typeof true;      // "boolean"
typeof undefined; // "undefined"

Muito útil para depurar quando algo não funciona como esperado.

Se um cálculo dá errado, o primeiro passo é conferir com typeof se os valores são do tipo que você imagina.
Parte 3 · Slide 14 · Mini prática

Qual é o tipo?

Antes de rodar no console, tente adivinhar o tipo de cada valor:

  • "25"
  • 25
  • true
  • [1, 2, 3]
  • { nome: "Ana" }
  • undefined

Dica: array e object técnicamente são do tipo "object" para o typeof — um detalhe curioso do JS!

Operadores

Fazendo o JS calcular e decidir
Parte 4 · Slide 15

Operadores aritméticos

+

soma (ou junta textos)

-

subtração

*

multiplicação

/

divisão

%

resto da divisão

++ / --

incrementa / decrementa

let total = 10 + 5;   // 15
let restante = 10 % 3; // 1
Parte 4 · Slide 16

== vs ===

Ambos comparam valores, mas de formas diferentes:

"5" == 5   // true
0 == false // true
"5" === 5   // false
0 === false // false
Use sempre === (igualdade estrita). Ele compara valor e tipo ao mesmo tempo, evitando surpresas.
Parte 4 · Slide 17

Operadores lógicos

&&

E — as duas condições precisam ser verdadeiras

||

OU — basta uma condição ser verdadeira

!

NEGÇÃO — inverte o valor lógico

const maiorDeIdade = true;
const temIngresso = false;

maiorDeIdade && temIngresso; // false
maiorDeIdade || temIngresso; // true
!temIngresso;                // true
Parte 4 · Slide 18

Template strings

Com crase (`) dá pra misturar texto e variáveis facilmente.

Jeito antigo:

const msg = "Olá, " + nome + "! Você tem " + idade + " anos.";

Com template string:

const msg = `Olá, ${nome}! Você tem ${idade} anos.`;

Muito usado para gerar textos e até HTML dinamicamente — vamos usar bastante nas próximas aulas.

05

Interagindo com o usuário

As primeiras janelas de interação do navegador
Parte 5 · Slide 19

alert()

Exibe uma janela simples com uma mensagem, que o usuário precisa fechar.

alert("Bem-vindo ao site!");

Ótimo para testes rápidos, mas pouco usado em sites reais — interrompe a navegação.

Parte 5 · Slide 20

prompt()

Pede uma informação digitada pelo usuário e retorna essa resposta como texto.

const nome = prompt("Qual é o seu nome?");
console.log(nome);

O valor retornado por prompt() é sempre do tipo string, mesmo que o usuário digite números.

Parte 5 · Slide 21

confirm()

Mostra uma pergunta com botões de OK e Cancelar, retornando true ou false.

const quer = confirm("Deseja continuar?");
if (quer) {
  console.log("O usuário confirmou!");
}
Parte 5 · Slide 22

Juntando tudo

Com prompt, template strings e alert, já dá pra criar a primeira interação real do site:

const nome = prompt("Como você se chama?");
alert(`Olá, ${nome}! Seja bem-vindo(a) ao meu site.`);
Isso já é JavaScript mudando o comportamento da página de acordo com o usuário — a base de tudo que vem por aí.
06

Atividade desafiadora

Cartão de visita interativo
Parte 6 · Desafio

Cartão de visita interativo

Construa uma página simples (HTML + CSS que você já sabe fazer) que funciona como um cartão de visita digital.

O grande desafio: usar JavaScript puro para personalizar a experiência de cada visitante, sem recarregar a página.
Parte 6 · Desafio

O que o site precisa fazer

  • Ao carregar, usar prompt() para perguntar o nome do visitante
  • Exibir uma saudação personalizada na tela usando template string
  • Verificar a hora atual e mudar a mensagem: “Bom dia”, “Boa tarde” ou “Boa noite”
  • Usar confirm() para perguntar se o visitante quer ver mais informações sobre você

Dica: a hora atual pode ser obtida com new Date().getHours() — vale pesquisar!

Parte 6 · Desafio

Esqueleto para começar

const nome = prompt("Qual é o seu nome?");
const hora = new Date().getHours();

let saudacao;
if (hora < 12) {
  saudacao = "Bom dia";
} else if (hora < 18) {
  saudacao = "Boa tarde";
} else {
  saudacao = "Boa noite";
}

alert(`${saudacao}, ${nome}! Seja bem-vindo(a) ao meu cartão de visita.`);

A partir daqui, capriche no visual em HTML/CSS e personalize a mensagem com seu próprio estilo.
