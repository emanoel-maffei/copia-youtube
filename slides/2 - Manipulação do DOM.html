01

O que é o DOM

A ponte entre o HTML e o JavaScript
Parte 1 · Slide 1

Do HTML para uma árvore de objetos

Quando o navegador lê o HTML, ele não guarda só o texto — ele monta uma árvore de elementos na memória.

Essa árvore é o DOM: Document Object Model.

O JavaScript não edita o arquivo .html — ele edita essa árvore em memória, e o navegador redesenha a tela na hora.
Parte 1 · Slide 2

Do código à árvore

Este HTML:

<body>
  <header>
    <h1>Meu site</h1>
  </header>
  <p>Olá!</p>
</body>

Vira esta árvore de elementos:

  • body
  •   ↳ header
  •     ↳ h1 — “Meu site”
  •   ↳ p — “Olá!”
Parte 1 · Slide 3

Inspecionando o DOM ao vivo

Na aba Elements (ou Inspecionar) das DevTools, você vê o DOM em tempo real — inclusive mudanças feitas por JS.

  • O HTML original pode nunca mudar no arquivo
  • Mas o DOM na tela pode estar completamente diferente
  • Isso acontece o tempo todo em sites modernos (redes sociais, e-commerces...)

Testar direto no console das DevTools é uma das formas mais rápidas de aprender a manipular o DOM.

02

Selecionando elementos

Antes de mudar algo, precisamos encontrá-lo
Parte 2 · Slide 4

getElementById

Seleciona um único elemento pelo atributo id.

<h1 id="titulo">Olá!</h1>
const titulo = document.getElementById("titulo");
console.log(titulo);

Precisa do id exato, sem o # na frente.

Parte 2 · Slide 5

querySelector

Seleciona o primeiro elemento que combina com um seletor CSS.

const titulo = document.querySelector("#titulo");
const primeiroBotao = document.querySelector(".botao");
const paragrafo = document.querySelector("p");

Funciona com qualquer seletor que você já usa em CSS: #id, .classe, tag.

Parte 2 · Slide 6

querySelectorAll

Seleciona todos os elementos que combinam com o seletor, numa lista.

const botoes = document.querySelectorAll(".botao");

botoes.forEach(botao => {
  console.log(botao);
});

O retorno é uma NodeList — parecida com array, e já tem o método forEach.

Parte 2 · Slide 7

Qual usar?

getElementById

Rápido, mas só funciona com id

querySelector

Um elemento, com qualquer seletor CSS

querySelectorAll

Vários elementos, com qualquer seletor CSS

Na prática: querySelector e querySelectorAll resolvem quase tudo — são os mais usados hoje.

03

Lendo e alterando conteúdo

Fazendo o texto da página responder ao JS
Parte 3 · Slide 8

textContent

Lê ou substitui o texto puro de um elemento.

const titulo = document.querySelector("#titulo");

console.log(titulo.textContent); // lê o texto atual
titulo.textContent = "Novo título!"; // troca o texto
Parte 3 · Slide 9

innerHTML

Parecido com textContent, mas entende tags HTML dentro do texto.

const card = document.querySelector(".card");
card.innerHTML = "<strong>Promoção!</strong> Only today.";
Cuidado: nunca coloque texto digitado por outra pessoa direto no innerHTML sem tratar — é uma brecha clássica de segurança.
Parte 3 · Slide 10

value: lendo campos de formulário

Inputs não têm “texto dentro” — eles têm a propriedade value.

<input id="nome" type="text">
const campo = document.querySelector("#nome");
console.log(campo.value); // o que foi digitado
campo.value = "Preenchido pelo JS";
Parte 3 · Slide 11 · Mini prática

Combinando seleção + conteúdo

A lógica de quase toda interação em sites segue este padrão:

  • 1. Selecionar o elemento
  • 2. Ler ou calcular um valor
  • 3. Alterar o conteúdo / estilo
  • 4. O usuário vê a mudança na hora
const saida = document.querySelector("#resultado");
saida.textContent = `Você digitou: ${campo.value}`;
04

Estilos e classes via JS

Mudando a aparência com código
Parte 4 · Slide 12

element.style

Dá pra alterar propriedades CSS diretamente pelo JS.

const caixa = document.querySelector(".caixa");
caixa.style.backgroundColor = "tomato";
caixa.style.padding = "20px";

Propriedades com hífen no CSS (background-color) viram camelCase no JS (backgroundColor).

Parte 4 · Slide 13

Por que preferir classList

.style direto

Bom para 1 ou 2 propriedades pontuais

classList

Ideal para mudanças maiores: liga/desliga um conjunto de estilos já prontos no CSS

Boa prática: deixe os estilos no CSS (numa classe) e use o JS só para ligar/desligar essa classe.
Parte 4 · Slide 14

classList: add, remove, toggle

const caixa = document.querySelector(".caixa");

caixa.classList.add("destaque");     // adiciona a classe
caixa.classList.remove("destaque");  // remove a classe
caixa.classList.toggle("destaque");  // alterna: liga se estava desligada, e vice-versa
Parte 4 · Slide 15

classList.contains

Verifica se um elemento já tem uma classe — ótimo para decidir o que fazer.

const body = document.body;

if (body.classList.contains("tema-escuro")) {
  console.log("O site está no modo escuro");
} else {
  console.log("O site está no modo claro");
}

Essa é exatamente a lógica por trás de um botão de tema claro/escuro.

05

Criando e removendo elementos

Gerando HTML novo em tempo real
Parte 5 · Slide 16

createElement + appendChild

Dá pra criar um elemento do zero e encaixá-lo na página.

const novoItem = document.createElement("li");
novoItem.textContent = "Item novo";

const lista = document.querySelector("#lista");
lista.appendChild(novoItem);

appendChild insere o elemento como o último filho do elemento pai.

Parte 5 · Slide 17

Outras formas de inserir

Inserir como primeiro filho:

lista.prepend(novoItem);

Inserir antes de um elemento específico:

lista.insertBefore(novoItem, referencia);
Parte 5 · Slide 18

Removendo elementos

Para tirar um elemento da tela de vez:

const item = document.querySelector(".item-antigo");
item.remove();

Forma antiga (ainda vista por aí): pai.removeChild(item). Hoje, item.remove() é mais direto.

Parte 5 · Slide 19

Boas práticas

  • Prefira textContent a innerHTML quando for só texto
  • Evite recriar elementos demais dentro de loops sem necessidade
  • Separe estilo (CSS + classes) de comportamento (JS)
  • Sempre confira no console se o elemento foi realmente selecionado antes de alterá-lo
06

Atividade desafiadora

Transformador de página
Parte 6 · Desafio

Transformador de página

Pegue um site estático já pronto (o seu, de módulos anteriores, ou um novo simples) e transforme-o num site que reage.

O desafio: usar seleção de elementos, classes e criação de elementos para mudar a página sem recarregar nada.
Parte 6 · Desafio

O que o site precisa fazer

  • Um botão que alterna entre tema claro e tema escuro usando classList.toggle
  • Um botão que insere um novo bloco de conteúdo na página (ex: um novo card, um novo item de lista)
  • Um botão que remove esse bloco inserido
  • Usar querySelector/querySelectorAll para toda seleção de elementos

Capriche no CSS das duas versões de tema — isso já deve estar pronto antes de mexer no JS.

Parte 6 · Desafio

Esqueleto para começar

const botaoTema = document.querySelector("#botao-tema");
const botaoAdicionar = document.querySelector("#botao-adicionar");
const lista = document.querySelector("#lista");

botaoTema.addEventListener("click", () => {
  document.body.classList.toggle("tema-escuro");
});

botaoAdicionar.addEventListener("click", () => {
  const novoItem = document.createElement("li");
  novoItem.textContent = "Novo item adicionado!";
  lista.appendChild(novoItem);
});

Não se preocupe se addEventListener ainda for novidade — é exatamente o assunto da próxima aula. Por enquanto, use-o como “receita pronta”.
